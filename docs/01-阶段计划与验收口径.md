# 01 · 阶段计划与验收口径

> 方案实施周期 12–14 周，本项目按 Demo 里程碑压缩。每阶段结束必须有实际命令与输出摘要；旧阶段用例全量回归。

## 1. M1 契约与数据底座

**交付物**

- `docs/03-接口契约.md`：REST 规范、统一返回、分页、鉴权、错误码、按模块接口清单（字段级请求/响应）、状态机与枚举
- `docs/04-数据模型与种子.md`：表清单（字段/类型/索引/外键/统一字段）、Flyway 版本策略、种子规模与自洽规则
- `docs/05-权限矩阵.md`：角色 × 菜单/按钮/接口/数据范围，附「允许/拒绝」用例编号
- 后端骨架：Spring Boot 工程、Flyway、MyBatis-Plus、Security + JWT、统一响应/异常/审计切面、OpenAPI
- 前端骨架：Vue3 + Vite + Element Plus + Pinia + Router、登录页、主框架（侧栏/顶栏/面包屑/标签页）、动态路由与按钮权限
- 数据库：项目内 MySQL 8.0.46 实例（3307）、库 `icp_platform`、账号 `icp_app`
- 种子数据（示例规模，M1 冻结）：部门 8 / 岗位 6 / 用户 30 / 角色 6 / 菜单+按钮 88（6 目录 + 39 C + 43 F） / 制度 40（分类 12）/ 风险 40 / 控制点 60 / 控制矩阵 60 / 评价计划 4 / 评价任务 20 / 底稿 20 / 缺陷 30 / 整改 25 / 流程定义 6 / 任务 80 / 文档 40 / 公告 12 / 日程 20 / 消息 60 / 字典 20 / 参数 15 / 日志 300
- 流程运行数据（流程实例 60 / 待办 40 / 历史留痕）不写入 Flyway SQL（ACT_* 由 Flowable 自建，H2/MySQL 方言差异大且需引擎 API），改由 M2c `scripts/seed-flow.ps1` 调用流程 API 生成；**M1 只校验流程定义与表单静态种子**（`wf_process_meta` 6 条、`wf_form` 不少于 6 条）及 `wf_*` 表结构，流程实例/待办规模在 M2c 验收报告中记录。

**验收口径（M1 冻结）**

1. `scripts/db-reset.ps1`：停实例 → 重建库 → Flyway migrate → 种子 → `db-validate`，全绿且重复执行幂等
2. `db-validate` 校验：金额/数量自洽、状态机可达、外键无孤儿、日期顺序、权限矩阵完整性；失败即初始化失败
3. `scripts/build-backend.ps1`（`mvn -q clean verify`）零错误；`GET /actuator/health` = `UP`
4. 前端 `npm run build` 零错误；登录 → 菜单 → 角色切换冒烟通过
5. 契约字段与 DDL 一致（脚本比对）；提交 hash 写入 M1 报告（`docs/06-M1-验收报告.md`）

## 2. M2 业务实现（5 个批次，可并行分派）

**M2a 组织权限与审计**：部门树 / 岗位 / 用户 CRUD、角色/菜单/按钮、用户角色、角色菜单、数据权限（本人/本部门/本部门及下级）；登录（JWT access + refresh）、密码策略、失败锁定、在线用户；操作日志、登录日志、关键表变更审计。验收：组织/用户/角色/登录/越权拒绝 API 用例；菜单按角色动态渲染；日志落库。

**M2b 内控域**：制度库（分类/版本/生效日期/附件/关联流程/发布审批）、风险库（分类/等级/影响×可能性评分/责任人）、控制矩阵（风险—控制点—制度—流程—岗位关联与覆盖度）、内控评价（计划/任务/评分/底稿）、缺陷（登记/分级/整改任务/证据/复核关闭）。验收：制度→风险→矩阵→评价→缺陷→整改→复核全链路 API 用例 + 页面联调。

**M2c 流程协同**：6 条内置流程（制度发布、缺陷整改、评价计划、文档借阅、采购申请、用印申请）；待办/已办/抄送、催办、历史留痕、流程监控、超时预警、审批意见与附件、只读流程图（bpmn-js viewer）。验收：发起→审批（同意/驳回）→完成全链路；历史留痕可查；超时扫描命中。

**M2d 协同运营**：任务中心（计划/任务/子任务/优先级/截止提醒）、文档中心（目录/权限/版本/本地下载）、公告（已读）、站内信（SSE 实时）、日程。验收：任务提醒、文档下载拒绝用例、公告已读、SSE 推送。

**M2e 报表看板与预警**：内控覆盖率、风险分布、整改完成率、流程平均耗时、按部门/时间/等级钻取；超时任务/到期制度/高风险缺陷预警；定时任务（预警扫描、超时催办、评价计划）。验收：看板接口数据与 SQL 校验一致；预警生成与去重；定时任务可手动触发。

**批次门禁**：构建零错误；API 集成测试通过；角色允许/拒绝用例通过；旧阶段用例回归；前端无 console error。
