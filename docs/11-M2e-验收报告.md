## 7. 偏差与决策

1. **字典口径（D42）**：风险 1=高/2=中/3=低，「高风险」= level 1（12 条）；缺陷 1=重大/2=一般/3=轻微，「高风险缺陷」= severity 1（6 条未关闭）。docs/03 §7.1 原写反（level=3/severity=3），已按实际字典修订。
2. **覆盖率 covered** = 风险至少 1 条 **status=1 生效** 矩阵（M2b 原写任意矩阵行），与 M2b 结果一致（40/40）。
3. **工作台权限（D43）**：summary/trend 放行 `report:dashboard:view` 或 `dashboard:workbench:view` 或 `dashboard:todo:view`；报表/预警严格 `report:*`；不新增权限串（种子零改动）。
4. **定时器**：`@Scheduled(fixedDelay=600000)` + 只读 `sys_job(status=1)`，**不解析 cronExpression**（D40 口径）；`lastRunTime/lastResult` 为进程内内存态，重启清空。
5. **预警计算时机**：查询时实时计算，不做后台推送；扫描命中才写消息（未命中仅写审计）。
6. **越权 deptId 参数**：忽略并返回自身数据范围（R16 允许 ignore 或 40300，本轮选 ignore）。
7. **流程耗时**：仅统计已完成（`wf_business_link.status=1`）；`months` 1–12，默认 6。
8. **`sys_oper_log` 无 module 列**：job 审计按 `title='定时任务-<jobName>'` 过滤（docs/03 §7.1 已改）。
9. **新增端点 `/reports/tasks`**（R/W05 需要）：`report:process:view`，返回 `{items:[{status,count}],total,overdue}`。

## 9. 遗留 / 已知限制

1. 定时器不解析 cronExpression（固定 10 分钟）：若需按 cron 触发需引入解析（二期）。
2. `lastRunTime/lastResult` 重启即失（进程内）；未落表。
3. 报表为实时聚合，数据量大时性能依赖索引（当前种子规模无问题）；未做物化视图/汇总表。
4. 预警不做站内推送弹窗，只在预警中心与消息中心体现。
5. 工作台 60s 缓存：新增数据后可能延迟 ≤60s 才刷新（已在契约注明）。
6. 任务页「任务状态分布」依赖本次追加的 `/reports/tasks`；如后续契约冻结为不含该端点需同步降级。
