## 9. 本轮发现并修复的问题

1. **CORS 仅放行 5173**：`SecurityConfig.java:82` 导致 4173 预览下 POST 403 → 改为 `app.cors.allowed-origins`（默认 localhost/127.0.0.1 的 5173+4173，逗号分隔）并同时设置 `setAllowedOrigins`/`setAllowedOriginPatterns`（docs/03 §1.4）。
2. **隐藏菜单泄漏**：`visible=0` 的「表单管理(id 40)/催办管理(id 47)」经 icpadmin 登录返回 → 后端 `AuthService.buildMenuTree` 递归 `filterVisible`、`MenuNode` 增 `visible` 字段 + 单测 `loginMenuTreeFiltersInvisibleMenus`；前端删兜底菜单并加 `HIDDEN_MENU_PATHS` 兜底；6 角色均不再返回。
3. **种子测试文案进入演示数据**：`seed-flow.ps1` 的 `M2c seed policy running 1` 等 → 全量业务化中文（制度/评价/采购/用印/借阅/审批意见/催办），条数与状态不变；另修 11 处年份 hex 错拼（`2226年`→`2026年`）。
4. **V3 种子残留测试文本**：`icp_rectify.remark='M1 seed'`、采购 purpose 等 31 处 → 业务化文案（不改条数/金额/状态/日期）；同时 `sys_file.file_path` 从 `demo/` 回退 `seed/` 以匹配磁盘实体（否则下载返回 `40400 文件实体已丢失`）。
5. **待办详情暴露原始 ID**：部门/责任人/缺陷编号等显示数字 ID → 后端统一解析为名称并移除裸 `*Id`，`formSchema` 合入中文 label；s27 显示「部门 运营管理部 / 责任人 高敏 / 缺陷编号 QX-2026-020」。
6. **verify.ps1 fail-fast 失效**：子脚本输出被函数返回值捕获，`$ok` 变数组导致失败仍打印 PASS → 改 `& powershell ... | Out-Host` 后取 `$LASTEXITCODE`，复跑确认「真 PASS 才 PASS」。
7. **截图横向滚动残留**：点击标题后表格横向滚动导致 s27 标题列被裁 → 截图前统一 `window.scrollTo(0,0)` + 表格/滚动容器 `scrollLeft=0`，重出 28 张。
8. **侧栏页脚写死阶段名**：`M2d · 协同运营` → `V1.0 · 企业内控协同平台`（收起态 `V1.0`）。

## 10. 遗留与本阶段限制

1. 流程仅一级审批：无加签/转办/委托；每流程含「发起」节点（`assignee=${initiator}`），业务提交后发起人先确认再进入审批（设计，docs/10 §7.1）。
2. 矩阵唯一键 `uk_risk_control(risk_id, control_id)` 不含逻辑删除条件：删除后重建同组合返回 40002（docs/08 §8）。
3. 文档可见性非 ADMIN 仅「创建人 ∪ 授权命中 ∪ 已通过借阅」；附件仅本地存储。
4. SSE 单实例内存注册（每用户最多 3 连接）；超时/定时器为进程内 `@Scheduled`，不解析 cronExpression。
5. 报表为实时聚合（60s 缓存），无汇总表；自定义数据权限（5）与多租户仍暂缓。
6. Docker Compose 仅交付文件（M4），本机以 3307 独立实例 + 本机 Node/Java 运行；`check-docs` 待 M4 交付。
