## 6. 偏差与修复（本阶段实际发生）

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | 首版种子 `sys_role_menu` 与 `docs/05` 不一致（icpadmin 可见系统管理、staff 见全部内控菜单、exec 缺流程中心、admin 有业务写按钮、子菜单缺 `/system` 父节点） | 重做种子：`sys_menu 60→88`、`sys_role_menu 239→264`、`sys_user_role 31→30`（admin 只挂 ADMIN，D21）；菜单树补祖先；db-reset 两次幂等通过 |
| 2 | `db-validate` V15 在运行期复跑失败（日志/附件表随运行增长） | V15 对 `sys_oper_log`/`sys_login_log`/`sys_file` 改为「不少于种子数」（D23），其余 39 表精确相等 |
| 3 | 菜单接口实际返回嵌套树，`docs/03` 原写扁平 `parentId` | `docs/03 §2` 更新为嵌套树契约（M/C/F + children + 祖先必带），前端 `buildMenuTree` 兼容两种（D20） |
| 4 | 后端权限仅用单角色（admin 曾兼 MANAGEMENT）导致并集越权 | admin 仅 ADMIN，权限严格按矩阵（D21） |
| 5 | 前端 401 处理把登录失败当「登录过期」；刷新直达动态菜单页 404 | 前端修复：`/auth/*` 401 透传后端 message；路由守卫补注册后重试（`frontend/README.md` 记录） |
| 6 | 环境坑：PowerShell 5.1 无 `utf8NoBOM`、`mysql -h` 短参误解析、esbuild Temp 权限、MySQL 重启竞态 | 脚本统一 `--host=`、写 ASCII my.ini、esbuild TEMP 重定向到 `node_modules/.tmp`、mysql-stop/start 等进程退出（均已在脚本中固化） |
