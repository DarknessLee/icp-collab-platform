# 企业内控与协同运营管理平台开发方案

> 定位：单租户优先、预留多租户扩展；前后端分离；Vue3 前端；Java 后端；Docker Compose 一键部署，预留 K8s/Helm 企业部署。

---

## 一、总体目标与范围

### 1. 建设目标

构建一个覆盖“内控体系管理 + 流程协同 + 运营任务 + 风险预警 + 审计留痕”的一体化平台，实现：

- 制度、风险、控制矩阵、评价、缺陷整改闭环管理
- 审批流、任务、文档、消息、日程协同
- 内控指标、流程效率、整改率、合规率看板
- 组织权限、数据权限、操作审计、附件管理
- 一键部署、可备份、可监控、可回滚

### 2. MVP 优先范围

一期建议先落地：

1. 组织权限与 SSO/JWT 登录
2. 流程引擎与表单/审批中心
3. 制度库、风险库、控制矩阵
4. 内控评价、缺陷整改闭环
5. 协同任务、文档中心、公告消息
6. 报表看板与审计日志
7. Docker Compose 一键部署

二期扩展：合同/采购/费用等业务插件、低代码表单、Elasticsearch 检索、移动端、K8s Helm、多租户。

## 二、总体架构

```text
浏览器/移动H5
   │ HTTPS
   ▼
Nginx（Vue3 静态资源 + /api 反向代理）
   │
   ▼
Spring Boot 后端（REST API / JWT / RBAC / 审计 / 流程）
   ├── MySQL 8：业务数据、流程配置、审计日志
   ├── Redis：缓存、会话、分布式锁、验证码
   ├── MinIO：附件、制度文件、整改证据
   ├── Flowable：审批流、任务、流程历史
   └── 定时任务：预警扫描、超时催办、评价计划
```

部署形态：

- 标准版：Docker Compose 一键部署
- 企业版：Helm Chart 部署到 K8s
- 离线版：镜像 tar 包 + 初始化 SQL + 部署脚本

## 四、功能模块规划

### 1. 组织与权限

- 部门、岗位、用户、角色、菜单、按钮权限
- RBAC + 数据权限：本人/本部门/本部门及下级/自定义部门
- 统一登录：账号密码、JWT、预留 OAuth2/LDAP/AD
- 密码策略、登录失败锁定、在线用户

### 2. 内控管理

- 制度库：制度分类、版本、生效日期、附件、关联流程
- 风险库：风险分类、等级、责任人、影响/可能性评估
- 控制矩阵：风险—控制点—制度—流程—责任岗位关联
- 内控评价：评价计划、评价任务、评分、底稿
- 缺陷管理：缺陷登记、分级、整改任务、证据上传、复核关闭
- 合规检查与审计跟踪

### 3. 流程协同

- BPMN 流程设计、表单绑定、条件分支
- 待办/已办/抄送/催办/委托/转办
- 流程监控、超时预警、流程历史留痕
- 审批意见、附件、电子签名位预留

### 4. 协同运营

- 任务中心：计划、任务、子任务、优先级、截止提醒
- 文档中心/知识库：目录、权限、版本、在线预览预留
- 公告、消息、日程、会议纪要
- 站内信 + WebSocket/SSE 实时提醒，邮件可选

### 5. 报表与预警

- 内控覆盖率、风险分布、整改完成率、流程平均耗时
- 超时任务、到期制度、高风险缺陷预警
- 看板按部门/时间/风险等级钻取

### 6. 系统与审计

- 字典、参数、消息模板、导入导出
- 操作日志、登录日志、数据变更审计、流程留痕
- 附件管理、定时任务、健康检查

## 五、数据模型概览

核心表建议：

- 权限：`sys_user`、`sys_dept`、`sys_role`、`sys_menu`、`sys_user_role`、`sys_role_menu`、`sys_role_dept`
- 内控：`icp_policy`、`icp_risk`、`icp_control`、`icp_evaluation`、`icp_defect`、`icp_rectify`
- 流程：Flowable 自带 `ACT_*` 表 + `wf_form`、`wf_business_link`
- 协同：`coll_task`、`coll_doc`、`coll_notice`、`coll_schedule`、`coll_message`
- 系统：`sys_file`、`sys_audit_log`、`sys_login_log`、`sys_dict`、`sys_config`

约定：

- 统一字段：`id`、`tenant_id`（预留）、`create_by`、`create_time`、`update_by`、`update_time`、`deleted`
- 使用 Flyway 管理数据库版本，初始化 SQL 幂等
- 审计日志采用“业务日志 + 流程历史 + 关键字段变更记录”

## 七、一键部署方案

### 1. Docker Compose 服务

- `frontend`：Nginx 托管 Vue3 `dist`，反代 `/api` 到后端
- `backend`：Spring Boot 容器，健康检查 `/actuator/health`
- `mysql`：初始化 SQL、数据卷
- `redis`：缓存与锁
- `minio`：附件存储，初始化 bucket
- 可选：`prometheus`、`grafana`、`loki`

### 2. 部署脚本

`deploy.sh` 流程：

1. 检查 Docker/Compose
2. 复制 `.env.example` 为 `.env`，校验必填项
3. 构建或加载离线镜像
4. `docker compose up -d`
5. 等待 MySQL/后端健康检查
6. 执行 Flyway/初始化管理员
7. 输出访问地址与初始账号，提示修改密码

示例命令：

```bash
cd deploy
cp .env.example .env
./scripts/deploy.sh
# 访问 http://服务器IP
```

离线部署：

```bash
docker save -o platform-images.tar ...
docker load -i platform-images.tar
./scripts/deploy.sh --offline
```

### 3. 运维能力

- 数据卷持久化：MySQL、MinIO、Redis
- `backup.sh`：mysqldump + MinIO 镜像备份
- 镜像 tag 版本化，支持回滚
- 日志 JSON 输出，按天轮转
- 资源建议：4C8G 起步，磁盘 100GB 起

## 八、安全与合规设计

- JWT 短令牌 + Refresh Token；密码 BCrypt
- RBAC + 数据权限双层校验
- 接口鉴权、防越权、防水平越权
- SQL 注入、XSS、CSRF 防护；文件类型白名单与大小限制
- 敏感字段 AES 加密、页面脱敏
- 操作日志、登录日志、流程留痕，关键日志哈希链防篡改
- 附件预签名上传，MinIO 私有桶
- 备份加密，定期恢复演练
- 等保二级/三级要求可按需补充：双因子、密码策略、审计留存周期

## 九、测试与验收指标

- 单元测试、接口集成测试、Playwright E2E
- JMeter 压测：目标 200–500 并发，核心接口 P95 < 500ms
- 验收场景：
  1. 一键部署 30 分钟内完成
  2. 登录、菜单、数据权限正确
  3. 制度—风险—控制矩阵—评价—缺陷—整改闭环
  4. 审批流程待办、催办、历史留痕完整
  5. 审计日志可查询，关键操作可追溯
  6. 备份恢复演练通过

## 十一、关键风险与应对

| 风险 | 应对 |
|---|---|
| 流程引擎复杂 | 先固化 5–8 个核心流程，表单引擎分期 |
| 数据权限复杂 | 统一数据权限拦截器，先支持部门维度 |
| 一键部署环境差异 | 固定镜像版本、健康检查、离线包、部署自检 |
| 内控业务变化 | 控制矩阵与流程解耦，配置化 |
| 审计要求高 | 关键操作全留痕，日志留存周期可配置 |

**建议落地顺序**：先做“组织权限 + 流程审批 + 制度风险控制矩阵 + 整改闭环 + 任务文档 + 看板 + Docker Compose 一键部署”的 MVP，再扩展合同采购费用、低代码表单、移动端和 K8s Helm。
