# docs/14 · 用户手册

- 适用版本：企业内控与协同运营管理平台 V1.0（未发表）
- 适用对象：系统管理员、内控管理员、部门负责人、普通员工、审计员、管理层
- 演示入口：本机 `http://127.0.0.1:4173`（或开发模式 `http://127.0.0.1:5173`）；演示账号见 §1.2
- 界面截图：`docs/screenshots/`（S01–S28，索引 `INDEX.md`）

---

## 1. 快速上手

### 1.1 登录

1. 打开系统地址，进入登录页（图 S01）。
2. 输入用户名、密码，点击「登录」。登录成功进入工作台。
3. 密码错误提示「用户名或密码错误」；连续失败 **5 次**账号锁定 **15 分钟**（提示剩余时间），可联系管理员解锁/重置。
4. 演示账号在登录页提供快捷填充按钮（仅演示环境）。

### 1.2 演示账号与角色

| 账号 | 角色 | 可见范围（摘要） |
| --- | --- | --- |
| `admin` | 系统管理员（ADMIN） | 全部系统管理 + 业务/流程/协同**只读**（三权分立：不参与业务审批） |
| `icpadmin` | 内控管理员（ICP_MANAGER） | 内控业务全量 + 流程审批/监控 + 协同全量；无系统管理 |
| `dept01` | 部门负责人（DEPT_MANAGER） | 本部门及下级的数据；可审批、可写制度/评价/协同 |
| `staff01` | 普通员工（EMPLOYEE） | 本人数据；可发起流程、处理自己被指派的待办、提交整改 |
| `auditor` | 审计员（AUDITOR） | 全局只读 + 日志审计（系统管理仅「日志审计」） |
| `exec` | 管理层（MANAGEMENT） | 全局只读 + 作为审批人处理待办 |

密码统一 `Icp@2026`；`dept02`–`dept06`、`staff02`–`staff20` 同规则。

### 1.3 界面结构

- **左侧菜单**：按角色权限动态生成；隐藏菜单（`visible=0`）不显示。
- **顶部**：面包屑、「我的待办/消息」入口、当前角色标签、用户菜单（个人中心/退出）。
- **标签页**：已打开页面以多标签保留，可关闭；刷新后回到首页。
- **按钮级权限**：无权限的按钮不显示；直接访问越权页面显示 403 页（图 S25）。

## 2. 工作台（首页）

登录后默认进入工作台（图 S02）：

- **8 张指标卡**：制度总数/有效数、风险总数/高风险数、控制矩阵覆盖率、缺陷总数/未关闭、整改完成率、待办审批数、超期任务、未读消息。
- **近 6 个月趋势**：新增制度/缺陷（柱）+ 流程平均耗时（折线）。
- **快捷入口**：查看待办审批、消息中心、预警中心；右上「刷新」。
- 数字由后端实时聚合（60 秒缓存），按当前用户数据权限过滤；点击卡片可跳转对应列表。

> 管理层/审计员只读：可见数据但无写按钮。

## 3. 内控业务

### 3.1 制度库（图 S04、S26）

1. 左侧分类树（按分类筛选）+ 右侧列表（编码/名称/分类/状态/生效日期/负责人）。
2. 「新建制度」：填写名称、分类、归属部门、负责人、生效日期、正文（可选附件），保存为**草稿**。
3. 草稿行操作：**编辑 / 提交审批 / 废止 / 删除 / 详情**。
   - 提交审批 → 状态「审批中」，同时生成流程实例，审批人收到待办；
   - 审批通过 → 状态「生效」并写生效时间；驳回 → 回到草稿并可修改后重新提交；
   - 废止 → 状态「废止」；已生效制度不可删除。
4. 「导出」下载当前筛选结果 CSV（UTF-8 BOM，Excel 可直接打开）。
5. 详情页可看基本信息、正文与审批历史（图 S26）。

### 3.2 风险库（图 S05）

1. 列表按分类/等级/状态筛选；等级由「可能性 × 影响」自动计算（≥15 高、≥8 中，其余低），弹窗内实时预览分值。
2. 新建/编辑风险：名称、分类、归属部门、责任人、可能性(1–5)、影响(1–5)、描述、应对措施。
3. 行操作：编辑、启停（状态切换）、详情。

### 3.3 控制点

- 维护控制点名称、控制类型（预防/检查/纠正）、频率、责任岗位、关联制度，供控制矩阵引用。

### 3.4 控制矩阵与覆盖率（图 S06）

1. 矩阵行 = 风险 × 控制点；新建时选择风险与控制点（同一组合只能存在一条，重复提交提示「唯一冲突」）。
2. 顶部覆盖率卡片：覆盖风险数/风险总数与百分比（覆盖率 = 至少关联 1 个控制点的风险占比）。
3. 支持按风险/控制点筛选，导出 CSV。

### 3.5 内控评价（图 S07）

1. 「评价计划」tab：新建计划（名称、年度/期间、范围部门、负责人）→ 保存草稿 → **提交审批** → 审批通过后状态「执行中」。
2. 计划行「启动」：按控制矩阵模板批量生成评价任务（重复启动幂等，不会重复生成）。
3. 「评价任务」tab：任务状态 待评价/进行中/已完成/逾期；点「处理」填写评分与结论、上传底稿（附件）后提交。
4. 计划「完成/关闭」：需任务全部提交（门禁），关闭后只读。

### 3.6 缺陷与整改（图 S08、S09）

1. 缺陷台账：登记缺陷（名称、等级、发现部门、责任人、描述、期限），状态 登记/整改中/待复核/关闭。
2. 「发起整改」：填写整改计划与期限 → 整改单状态「待复核」并发起审批流；审批人在待办中处理。
3. 审批通过 → 整改「已通过」、缺陷「待复核」；驳回 → 整改「待整改」、缺陷回到「整改中」，可补充证据后重新提交。
4. 提交整改证据（附件，逗号分隔多个文件 ID 由界面自动处理）→ 复核人「关闭缺陷」。
5. 「整改复核」页可查看整改单、证据与审批历史，执行 通过/驳回/关闭。

## 4. 流程中心

### 4.1 我的待办（图 S10、S27）

- 列表：标题、流程类型、业务单号、当前节点、发起人、发起/截止时间；超时任务红色标记。
- 筛选：流程类型、标题/业务单号关键字；分页。
- 「处理」打开详情抽屉（图 S27）：
  - 表单信息（中文标签，部门/责任人/编号等已解析为名称）；
  - 流转历史（时间线）；
  - 流程图（BPMN 只读高亮）；
  - 底部操作：**同意 / 驳回 / 催办**（是否显示由权限与节点决定）。
- 同意：填写审批意见 → 流转到下一节点/结束；驳回：必须填写意见 → 回到发起人；催办：提醒当前办理人（不改流程状态，可多次）。

### 4.2 我的已办 / 我发起（图 S11 相关）

- 已办：我处理过的任务（含我同意/驳回的）与当前状态。
- 我发起：我发起的流程实例，可查看进度；被驳回的实例可「重新提交」（同实例续流，历史保留）。

### 4.3 流程监控 / 流程实例 / 流程定义

- 监控（管理员/内控管理员/管理层）4 张统计卡 + 列表：运行中/已完成/已驳回/超时筛选；按流程类型与关键字检索。
- 流程实例：全部实例列表 + 详情抽屉（业务数据、节点、历史）。
- 流程定义：6 条内置流程（制度发布、缺陷整改、评价计划、文档借阅、采购申请、用印申请），可看 BPMN 图。

### 4.4 申请单（图 S12、S13、S14）

- **采购申请**：新建（物品明细、数量、单价、金额自动两位小数、预算校验、事由）→ 提交后进入流程；列表可看状态与「流程跟踪」。
- **用印申请**：新建（印章类型、用印事由、日期）→ 提交审批。
- **文档借阅**：选择文档、填写借阅事由与期限 → 提交；审批通过后可下载；「归还」把借阅单置为已归还。

> 所有流程发起后有「发起」节点：发起人需在待办中确认提交（同意）后，才流转到审批人；这是设计行为。

## 5. 协同运营

### 5.1 任务中心（图 S15）

- 我的任务/我创建的任务两个视角；按优先级/状态/截止日期/关键字筛选。
- 新建任务：标题、描述、指派人、优先级、计划起止时间、父任务（子任务）。
- 行操作：开始、完成、取消、评论、提醒（给指派人发站内消息）；逾期任务红色标记。

### 5.2 文档中心（图 S16）

- 左侧目录树（可维护）；右侧文档列表（名称/分类/版本/状态/负责人）。
- 上传文档 → 保存为草稿 → 「发布」（可见）→ 「归档」（只读）。
- 「权限」抽屉：为全员/角色/部门/用户配置 查看/下载/编辑 权限。
- 下载：需已发布/归档 + 命中权限；已有通过的借阅单也可下载；否则 403 提示。
- 在线预览：已发布文档点「预览」在弹窗内直接查看 PDF / 图片（不产生下载次数，无权限时提示发起借阅）；其他格式提示下载后查看。
- 版本：上传新文件自动升次版本（V1.0 → V1.1）。

### 5.3 公告、消息与日程（图 S17、S18、S19）

- 公告：按范围（全公司/部门/角色）发布；员工在「公告」中查看，打开即已读（幂等），可看未读数。
- 消息中心：全部/未读筛选，批量已读；SSE 实时推送（右上角未读数即时应答），系统消息由管理员发送。
- 日程：月历视图 + 列表；新建日程（标题、起止时间、参与人、提醒），可取消（状态「已取消」）。

## 6. 报表与预警（图 S03、S20、S21）

- 报表中心 5 个页面：内控概览（覆盖率趋势/等级分布）、制度报表、缺陷报表、任务报表、预警中心。
- 支持时间/部门/等级筛选与钻取（点击图表下钻列表）；导出 CSV。
- 预警中心 4 类：超时任务、到期制度、高风险缺陷、逾期整改；显示统计卡 + 列表。
- 管理层/审计员只读查看。

## 7. 系统管理（仅系统管理员；审计员仅日志审计）

| 页面 | 功能 |
| --- | --- |
| 部门管理 | 树形维护；新增/编辑/删除（有子部门或用户时禁止删除）；编码可留空自动生成 |
| 岗位管理 | 岗位编码/名称/排序/状态 |
| 用户管理（图 S23 相关） | 新增/编辑/删除/停用启用/重置密码/分配角色；筛选部门/状态/关键字；「在线会话」查看并强制下线 |
| 角色管理（图 S23） | 新增/编辑/删除（内置角色不可删）；「菜单授权」勾选菜单与按钮权限（保存后立即生效） |
| 菜单管理 | 目录/菜单/按钮三级维护；按钮权限标识用于前端显隐与后端校验 |
| 字典管理 | 字典类型与字典项；内置类型不可删、有字典项不可删 |
| 系统参数 | 修改运行时参数（上传大小/类型、登录锁定、密码长度、风险阈值、流程超时） |
| 日志审计 | 操作日志/登录日志/变更日志三类，支持筛选与详情（含 traceId） |
| 定时任务 | 5 个内置任务查看最近执行；「运行」立即执行一次（写消息 + 审计） |

### 7.1 角色与数据权限

- 6 个内置角色；数据权限 4 档：本人 / 本部门 / 本部门及下级 / 全部（自定义部门为二期）。
- 管理员对业务数据**只读**（三权分立），内控管理员负责业务，审计员只读审计。
- 修改角色菜单授权后，用户需重新登录或刷新页面以刷新菜单与按钮权限。

## 8. 个人中心（图 S24）

- 查看/编辑个人资料（姓名、手机、邮箱等）。
- 修改密码：需原密码；修改成功后当前会话失效，需重新登录。

## 9. 常见问题

| 问题 | 处理 |
| --- | --- |
| 看不到某个菜单 | 角色未授权该菜单；联系管理员在「角色管理 › 菜单授权」勾选后重新登录 |
| 按钮看不到 | 按钮权限未授予（前端按权限隐藏）；后端同样校验，越权会返回 403 |
| 提交后没有审批待办 | 先看「我的待办」是否有「发起」节点任务，确认后才会流转给审批人 |
| 数据比同事少 | 数据权限不同（本人/本部门/本部门及下级/全部） |
| 文档下载 403 | 未发布/未授权/无通过借阅；请联系文档负责人授权 |
| 密码忘记 | 管理员在用户管理内重置密码（演示环境统一 `Icp@2026`） |
| 页面空白/接口 403 | 检查后端是否启动（`/actuator/health`）与 CORS 端口（5173/4173） |
| 想恢复演示数据 | 管理员运行 `scripts\demo-reset.ps1`（会重建库并回到标准演示态） |
